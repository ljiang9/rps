# rps ✊✌️🖐️

终端石头剪刀布：和电脑对战。纯标准库，纯本地运行。

## 快速开始

```bash
python -m rps                # 无限局，输入 q 退出
python -m rps --rounds 5     # 固定 5 局
python -m rps --auto 3000    # 电脑内战 3000 局，看统计
```

## 玩法

- 每局输入你的招式：`石头` / `剪刀` / `布`
- 也接受英文（`rock` / `scissors` / `paper`，或 `r` / `s` / `p`）和拼音（`shitou` / `jiandao` / `bu`）
- 输入 `q` 退出；看不懂的输入会提示重输，不会崩溃
- 实时显示比分 `你 X : Y 电脑（平 Z）`，结束时公布总比分

## 示例

```
===== 石头剪刀布 （共 5 局） =====
输入：石头/剪刀/布（也可用 rock/scissors/paper 或拼音），q 退出

第 1 局，你出：石头
你：石头　电脑：剪刀　🎉 你赢了！
比分 你 1 : 0 电脑（平 0）
```

## 设计取舍

- 电脑出招用 `secrets.choice`（系统熵），不是 `random`——虽然只是游戏，但"公平"值得认真。
- 规则就是标准石头剪刀布：石头赢剪刀、剪刀赢布、布赢石头。
- `--auto` 是电脑内战：双方都是均匀随机，胜/负/平理论上各约 1/3，可用来验证随机性没有偏斜。

## 已知局限

- 纯终端交互，无图形界面；管道下请用 `--auto`。
- 无记分持久化——退出即清零，本来就是随手玩两局。
- 电脑是纯随机的，没有"读心术"或难度等级。
